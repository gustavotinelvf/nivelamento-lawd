Sobre o REWIND

O REWIND é uma curadoria de músicas organizada por mood, não por gênero. Cada fita guarda uma faixa pra um tipo de dia: madrugada, sol, melancolia, rock'n'roll.

O site foi feito como projeto de nivelamento da LAWD (Liga Acadêmica de Desenvolvimento Web, UFS), usando apenas HTML, CSS e JavaScript básico.
